# Ultrasonic sensor + OLED (ESP32 DevKit)

На модуле с пинами **VCC / GND / TRIG / ECHO** — это не UART-лидар, а ультразвуковой дальномер типа **HC-SR04** (или совместимый).

## Подключение

| Датчик | ESP32 | GPIO |
|--------|-------|------|
| VCC    | 5V    | — |
| GND    | GND   | — |
| TRIG   | выход ESP32 | **GPIO 17** |
| ECHO   | вход ESP32  | **GPIO 16** |

| OLED (I2C) | ESP32 | GPIO |
|------------|-------|------|
| SDA        | SDA   | **GPIO 21** |
| SCL        | SCL   | **GPIO 22** |
| VCC        | 3V3   | — |
| GND        | GND   | — |

## Как это работает

- **TRIG** — ESP32 посылает короткий импульс «измерь».
- **ECHO** — датчик отвечает импульсом, длина которого = время полёта звука.
- Прошивка считает расстояние и рисует его на OLED.

## Важно

- Общий **GND** у ESP32, датчика и OLED обязателен.
- HC-SR04 обычно питается от **5V**.
- На **ECHO** у многих модулей **5V логика**. ESP32 — 3.3V. Если модуль не «3.3V compatible», поставь делитель на ECHO:
  - `ECHO --[1k]--+-- GPIO16`
  -              `--[2k]-- GND`
- Дальность HC-SR04 примерно **2–400 см**. Ближе 2 см часто шум.

## Что на OLED

- `SONAR` + состояние: `SCAN`, `OK`, `CLOSE!`, `FAR`, `LOST`
- Расстояние в см, длина импульса ECHO в микросекундах
- Radar-анимация с точкой цели

## Прошивка

```bash
cd src/esp32dev/lidar
pio run -e esp32dev -t upload
pio device monitor
```
