# NRF24L01 — двунаправленная связь двух ESP32 DEV

Обе платы — `ESP32 DEV`. Распиновка идентична: один и тот же скетч можно перетащить между платами, отличаются только флаги `-DNODE_A` / `-DNODE_B` в `platformio.ini` и набор подключённой периферии.

## NRF24L01+ (модуль радио)

| Радио  | ESP32 DEV (обе платы) |
|--------|-----------------------|
| `VCC`  | `3V3` (НЕ 5 В, повесить керамику 100 нФ + электролит 10 µF рядом с модулем) |
| `GND`  | `GND` |
| `CE`   | `GPIO4` |
| `CSN`  | `GPIO5` |
| `SCK`  | `GPIO18` |
| `MOSI` | `GPIO23` |
| `MISO` | `GPIO19` |
| `IRQ`  | не подключать |

## Светодиод + кнопка (на обеих платах)

| Элемент             | Пин ESP32                                  |
|---------------------|--------------------------------------------|
| LED (анод через 220 Ω) | `GPIO2` → LED → 220 Ω → `GND` (или использовать встроенный синий) |
| Кнопка               | `GPIO15` ↔ `GND` (внутренний pull-up) |

## OLED SSD1306 128×64 (ТОЛЬКО на `node-a`)

| OLED  | ESP32 DEV (node-a) |
|-------|--------------------|
| `VCC` | `3V3` |
| `GND` | `GND` |
| `SDA` | `GPIO21` |
| `SCL` | `GPIO22` |

Адрес I²C: `0x3C`.

## Питание

- Радио критично к питанию — питать от `3V3` платы и обязательно ставить кондёр 10 µF + 100 нФ у `VCC` модуля.
- Общая земля между платами не нужна (они физически разделены), но обе должны иметь стабильные 3.3 В.

## Радиопротокол

- Канал `76`, скорость `1 Mbps`, мощность `RF24_PA_LOW`, авто-ACK включён.
- Пайпы: `node-a` пишет в `"NODEB"`, читает `"NODEA"`; `node-b` — наоборот.
- Пакет (`common/protocol.h`):
  - `cmd`: `0x01 BLINK`, `0x02 ACK`, `0x03 PING`
  - `fromId`, `blinkMs`, `blinkCount`, `seq`, `uptimeMs`
- Каждый узел раз в 2 с автоматически шлёт соседу «моргни 2 раза по 200 мс». Нажатие кнопки — внеплановое «моргни 5 раз по 120 мс».
- Сосед, получив `CMD_BLINK`, мигает своим LED (неблокирующе) и отвечает `CMD_ACK`. `node-a` показывает счётчики и последнюю команду на OLED.

## Сборка и прошивка

```bash
cd node-a && pio run -t upload   # /dev/ttyUSB0
cd node-b && pio run -t upload   # /dev/ttyUSB1
```

Подправь `upload_port` в `platformio.ini` каждой папки под свои реальные порты.
