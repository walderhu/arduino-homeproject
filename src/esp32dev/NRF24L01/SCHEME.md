# Полная схема подключения

Две одинаковые ESP32 DEV + два модуля NRF24L01+. На `node-a` дополнительно OLED. На обеих — светодиод и кнопка.

```
┌───────────────────── NODE-A (с OLED) ─────────────────────┐         ┌────────── эфир 2.4 ГГц ──────────┐         ┌──────────── NODE-B ────────────┐
│                                                            │         │                                  │         │                                 │
│   ESP32 DEV                                                │         │                                  │         │   ESP32 DEV                    │
│                                                            │         │                                  │         │                                │
│   3V3 ──┬──► NRF24 VCC ──── 10µF ── GND                    │         │                                  │         │   3V3 ──┬──► NRF24 VCC ── 10µF ─ GND
│         └──► OLED  VCC                                     │         │                                  │         │         │                       │
│   GND ──┬──► NRF24 GND, OLED GND, LED-кат, кнопка          │         │                                  │         │   GND ──┴──► NRF24 GND, LED-кат, кнопка
│   GPIO4 ──► NRF24 CE                                       │         │                                  │         │   GPIO4 ──► NRF24 CE           │
│   GPIO5 ──► NRF24 CSN                                      │   <───  │      пайп  "NODEA" (читает A)    │  <───   │   GPIO5 ──► NRF24 CSN          │
│   GPIO18 ─► NRF24 SCK                                      │   ───>  │      пайп  "NODEB" (читает B)    │  ───>   │   GPIO18 ─► NRF24 SCK          │
│   GPIO19 ─► NRF24 MISO                                     │         │      канал 76, 1 Mbps, авто-ACK  │         │   GPIO19 ─► NRF24 MISO         │
│   GPIO23 ─► NRF24 MOSI                                     │         │                                  │         │   GPIO23 ─► NRF24 MOSI         │
│   GPIO21 ─► OLED SDA                                       │         │                                  │         │                                │
│   GPIO22 ─► OLED SCL                                       │         │                                  │         │                                │
│   GPIO2  ─► LED анод ── 220 Ω ── GND                       │         │                                  │         │   GPIO2  ─► LED анод ─ 220 Ω ─ GND
│   GPIO15 ─► кнопка ── GND  (INPUT_PULLUP)                  │         │                                  │         │   GPIO15 ─► кнопка ─ GND       │
│                                                            │         │                                  │         │                                │
└────────────────────────────────────────────────────────────┘         └──────────────────────────────────┘         └─────────────────────────────────┘
```

## 1. NRF24L01+ → ESP32 DEV (одинаково на обеих платах)

| Радио | ESP32 DEV | Назначение            |
|-------|-----------|-----------------------|
| 1 GND | GND       | Земля                 |
| 2 VCC | **3V3**   | Питание (НЕ 5 В!)     |
| 3 CE  | GPIO4     | Chip Enable           |
| 4 CSN | GPIO5     | SPI Chip Select       |
| 5 SCK | GPIO18    | SPI clock (HSPI/VSPI) |
| 6 MOSI| GPIO23    | SPI MOSI              |
| 7 MISO| GPIO19    | SPI MISO              |
| 8 IRQ | —         | не используем         |

**Обязательно:** между `VCC` и `GND` модуля поставить электролит **10 µF** + керамику **100 нФ** как можно ближе к разъёму радио — иначе модуль будет ловить помехи и `radio.write()` начнёт возвращать `false`.

```
NRF24L01+ (вид снизу, контакты к себе):

       ┌─────────┐
  GND ─┤ 1     2 ├─ VCC      ← сюда висит 10µF + 100нФ
   CE ─┤ 3     4 ├─ CSN
  SCK ─┤ 5     6 ├─ MOSI
 MISO ─┤ 7     8 ├─ IRQ
       └─────────┘
```

---

## 2. Светодиод (обе платы)

```
GPIO2 ─── [анод LED катод] ─── [резистор 220 Ω] ─── GND
```

| Контакт          | Куда           |
|------------------|----------------|
| LED анод (+)     | GPIO2          |
| LED катод (−)    | через 220 Ω на GND |

Можно использовать встроенный синий LED на плате ESP32 DEV (он уже сидит на `GPIO2`) — внешний тогда не обязателен.

---

## 3. Кнопка (обе платы)

```
GPIO15 ─── [одна нога кнопки   вторая нога] ─── GND
```

В прошивке пин сконфигурирован как `INPUT_PULLUP`, нажатие = `LOW`. Дополнительный внешний резистор не нужен.

---

## 4. OLED SSD1306 128×64 — только на `node-a`

| OLED  | ESP32 DEV (node-a) |
|-------|--------------------|
| GND   | GND                |
| VCC   | 3V3                |
| SCL   | GPIO22             |
| SDA   | GPIO21             |

Адрес I²C: `0x3C` (стандарт для модулей 0.96"). Если у тебя `0x3D` — поправь `OLED_ADDR` в `node-a/src/main.ino`.

---

## 5. Питание

- Каждая ESP32 DEV питается через свой USB (или 5 В на `VIN`).
- Радио и OLED — только от **3.3 В** (контакт `3V3` рядом с `EN`).
- Земли между двумя ESP **соединять не нужно**, они изолированы (связь по эфиру).
- Если NRF ловит сбросы при `radio.write()` — добавь второй кондёр 10 µF на радио или питай радио от отдельного LDO 3.3 В.

## 7. Что делает прошивка

- **Каждые 2 с** каждый узел шлёт соседу `CMD_BLINK` (моргни 2 раза по 200 мс).
- **Нажатие кнопки** — внеплановое `CMD_BLINK` (5 раз по 120 мс).
- Получатель мигает своим `GPIO2` неблокирующе и отвечает `CMD_ACK`.
- `node-a` выводит на OLED: счётчики TX/RX, число миганий, последнюю команду от соседа, секунды с последнего приёма, состояние LED.

## 8. Прошивка

```bash
cd node-a && pio run -t upload   # порт /dev/ttyUSB0
cd node-b && pio run -t upload   # порт /dev/ttyUSB1
pio device monitor               # лог в той же папке
```

Порты подправь в `platformio.ini` каждой папки под свои реальные.
